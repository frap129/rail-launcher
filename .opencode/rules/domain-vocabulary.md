# Domain Vocabulary

- Read `GLOSSARY.md` before naming a type, function, property or string.
- Never use a term the glossary marks `_Avoid_` (e.g. `item`, `wave`, `App` when meaning any Launchable).
- Add new domain terms to `GLOSSARY.md` in the same change that introduces them.
- Name paired actions with one toggling verb (`toggleFavorite`) or a verb pair over the same noun (`editFavorites` / `finishEditingFavorites`).
